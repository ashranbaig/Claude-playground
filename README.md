# Mirza Mohd Ashran Baig — Personal Site

A single-page personal branding site built from my GitHub profile README.
Plain HTML/CSS/JS in `index.html`, with no build step.

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.

## Deploy on GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → pick the branch and `/ (root)`.
